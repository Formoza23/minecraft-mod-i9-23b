# Minecraft Mod — CrystalLight

Учебный проект по дисциплине «Инструментальные средства разработки программного обеспечения».

Команда «Огузки», группа И9-23Б.

Участники: Бимеев Дамир, Огольцов Михаил.

Цель проекта: разработка мода Minecraft «CrystalLight» — блока «Светящийся кристалл» (Glowing Crystal), излучающего свет уровня 12, добыча которого возможна любой киркой, с крафтом из 3 кварца и 1 светопыли.
## Структура проекта
- src/main/java — исходный код проекта (Java-классы, в том числе класс точки входа).
- src/main/resources — ресурсы и конфигурационный файл проекта.
- ## Игровой объект
- glowing_crystal — блок «Светящийся кристалл», излучает свет (идентификатор crystallight:glowing_crystal).
