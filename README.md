# Minecraft Mod — CrystalLight

Учебный проект по дисциплине «Инструментальные средства разработки программного обеспечения».

Команда «Огузки», группа И9-23Б.

Участники: Бимеев Дамир, Огольцов Михаил.

Цель проекта: разработка мода Minecraft «CrystalLight» — блока «Светящийся кристалл» (Glowing Crystal), излучающего свет уровня 12, добыча которого возможна любой киркой, с крафтом из 4 аметиста и 5 светопыли.
## Структура проекта
- src/main/java — исходный код проекта (Java-классы, в том числе класс точки входа).
- src/main/resources — ресурсы и конфигурационный файл проекта.
- ## Игровой объект
- glowing_crystal — блок «Светящийся кристалл», излучает свет (идентификатор crystallight:glowing_crystal).
## Свойства объекта   
- Прочность (strength 3.0 / 6.0) — как у железного блока: кристалл прочный, но разрушаемый подходящим инструментом. - Светимость (luminance 8) — блок заметно освещает пространство, но слабее факела (14), поэтому не обесценивает другие источники света. - requiresTool() — добывается только киркой; рукой блок не выпадает.  
## Рецепт
- Блок создаётся из 5 светящейся пыли и 4 осколков аметиста. Светящаяся пыль отражает главное свойство блока (свет), аметист — «кристаллическую» природу. Стоимость умеренная: ресурсы доступны в середине игры, что соответствует прочности железа и средней светимости блока
- ## Поведение объекта   
- Блок «Светящийся кристалл» реагирует на использование игроком. 1. Исходное состояние: в мире размещён блок crystallight:glowing_crystal, в главной руке игрока ничего нет. 2. Действие игрока: нажать правую кнопку мыши по блоку. 3. Ожидаемый результат: над панелью предметов появляется сообщение «Светящийся кристалл тихо мерцает.»  Отрицательный сценарий: тот же щелчок по любому другому блоку (например, камню) не вызывает сообщения.  Проверка: сообщение на экране игрока.
- # CrystalLight   
- Мод для Minecraft (Fabric), добавляющий декоративный светящийся блок «Светящийся кристалл».   
- ## Игровой объект   
- - glowing_crystal — блок «Светящийся кристалл»   (идентификатор crystallight:glowing_crystal), излучает свет.   
- ## Совместимость   
- - Minecraft 1.21.10 - Fabric Loader [0.20.1] - Fabric API [0.138.4] 
- - Java 21   Другие версии не проверялись.   
- ## Установка   
- 1. Установите Minecraft 1.21.10 и Fabric Loader [0.20.1]. 2. Поместите Fabric API [0.138.4] и файл мода [crystallight-1.0.0.jar]    в папку mods игры (старую копию мода удалите). 3. Запустите игру с профилем Fabric и убедитесь, что блок    «Светящийся кристалл» доступен.   
- ## Использование  
- - Получение: творческий инвентарь, вкладка «Строительные блоки»,   либо команда /give @s crystallight:glowing_crystal. - Рецепт (верстак): светящаяся пыль и осколок аметиста в шахматном   порядке (G A G / A G A / G A G, где G — пыль, A — аметист). - Поведение: правая кнопка мыши по блоку пустой рукой показывает   сообщение над панелью предметов.   
- ## Свойства   
- - Прочность 3.0 / 6.0, светимость 8. - Добывается киркой (requiresTool).   
- ## Известные ограничения   
- - Добавлен один блок; других предметов нет. - Сообщение показывается при щелчке пустой рукой и не показывается   при приседании. - Проверена только версия Minecraft 1.21.10. - Названия объекта заданы на русском языке (ru_ru).
